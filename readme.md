<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Fixed Anvil Repair Cost is a minimalistic configurable mod which makes some changed to the anvil. You can set how many levels a repair should cost, forever. The cost does not increase. It's also possible to set the amount of materials needed for a repair and how much percent an item should be repaired by an action. </span></p>

<p>&nbsp;&nbsp;&nbsp;<span style="font-size:18px">All available config options:</span></p>
<div class="spoiler" style="margin-left:10px;padding-left:10px">
<p><span style="font-size:14px"><strong>repairCostLevelAmount</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 3, min 0, max 100</span><br><span style="font-size:13px">The amount of level it costs to repair an item on an anvil. A value of 0 keeps vanilla behaviour.</span><br><br><span style="font-size:14px"><strong>repairCostMaterialAmount</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 1, min 0, max 64</span><br><span style="font-size:13px">The amount of material it costs to repair an item on an anvil. A value of 0 keeps vanilla behaviour.</span><br><br><span style="font-size:14px"><strong>percentRepairedPerAction</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 0.3333, min 0, max 1.0</span><br><span style="font-size:13px">How much the item is repaired per action. By default 33.33%, so 3 of 'repairCostMaterialAmount' fully repairs any item.</span></p>
</div>
